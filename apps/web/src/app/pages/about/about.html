About CAD Agent Designer

Project status, compatibility, and where security and limitations live.

Status

CAD Agent Designer is an experimental alpha, not a hosted service. Installers are unsigned and macOS builds are not notarized; you deploy and operate your own backend.

Compatibility

CAD / platform Alpha behavior
FreeCAD, working FreeCADCmd / freecadcmd Headless create, modify, read, and export; an STL preview mesh uploads for the dashboard.
FreeCAD GUI-only, AppImage, Flatpak or Snap May need a manual path or a separate command-line install.
AutoCAD / AutoCAD LT Installation discovery only — no execution adapter shipped.
AutoCAD on Linux Not a supported target.

Security and limitations

  • Identity comes from a validated OIDC token; a request cannot choose its own owner.
  • Device pairing codes are one-use and expire in 10 minutes.
  • Revoking a device blocks new requests and cancels queued jobs, but cannot stop one already running locally.
  • Native CAD files stay on the linked computer. The STL preview mesh is the exception: capped at 25 MiB per file, with a 500 MiB per-device quota.
  • The store supports one backend instance; this alpha is not built to scale horizontally.
