Three steps to connect

  1. Install the connector

    Run the CAD Agent Designer agent on the computer with FreeCAD, or AutoCAD for detection only.

  2. Link the machine

    Pair it to your account with a one-time code that expires in 10 minutes.

  3. Connect Claude or ChatGPT

    Add the CAD Agent Designer connector in your assistant's settings and sign in.

What it can do today

  • FreeCAD — headless create, modify, read, and export on named designs: primitives, booleans, transforms, extrusion, scene reads, STEP/STL/DXF export.
  • AutoCAD / AutoCAD LT — installation and edition detected only; no execution yet.

Security posture

  • Every operation runs from a fixed allowlist — nothing free-form ever reaches the machine.
  • Native files (.FCStd, .dwg) never leave the computer that owns them.
  • Only a generated STL preview mesh uploads, and only so the dashboard can render it.
